This page tracks corrections and material updates to facts published on this
site: cost figures, legal citations, timeline facts, and any retraction.
Entries are never deleted or edited away — if a correction is itself later
found wrong, a new entry is added. See `ARCHITECTURE.md` section 9 for the
full policy. Code and site-mechanics changes are tracked separately in the
repository's `CHANGELOG.md`, which is a different, developer-facing log.
