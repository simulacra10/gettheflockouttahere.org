**Isn't this just for catching stolen cars and Amber Alerts?**
Flock markets its cameras around those use cases, but the system logs every
passing vehicle regardless of any suspicion, and retains that data for a
period set by the deploying agency — see [What is Flock?](/what-is-flock/).

**Who can access the data?**
It depends on the agency's configuration, but Flock's network model allows
participating agencies to share reads with each other, including
out-of-state agencies, without a warrant.

**Is this site affiliated with the Town of Easton or Talbot County?**
No. See [About](/about/).

**I found an error on this site. What do I do?**
Please report it through the [Discord](/take-action/) channel.
